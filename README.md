# 위아 WIA 웹 서비스 (시범 운영판)

선생님 화면, TV 화면, 학생 웹을 하나의 웹 서비스로 묶었어요. 한 번 인터넷에 올려 두면 **설치 없이 주소만 열어서** 써요.

## 주소 세 개

서비스를 올리면 `https://서비스이름.onrender.com` 같은 주소가 생겨요.

| 누가 | 주소 | 하는 일 |
|---|---|---|
| 학생 | `https://서비스이름.onrender.com/` | QR을 찍거나 6자리 코드 입력 → 닉네임 → 수업 참여 |
| 선생님 (모니터) | `https://서비스이름.onrender.com/teacher` | 로그인, 클래스·콘텐츠 관리, 수업 진행 버튼, 결과 |
| TV | `https://서비스이름.onrender.com/teacher?tv=1` | 학생들에게 보여 줄 화면만 크게 (버튼 없음) |

TV 주소는 직접 칠 필요 없어요. 수업을 열면 나오는 **"TV 화면 열기"** 버튼이 열어 줘요.

## 처음 계정

- 아이디 `wia2026` / 비밀번호 `12345678` (배포할 때 `TEACHER_ID`, `TEACHER_PW`를 넣으면 그 값으로 만들어져요)
- 로그인한 뒤 오른쪽 위 계정 메뉴에서 바로 바꿔 주세요.

## 어떤 서버를 쓰나요

**Render**(웹 서비스 호스팅)를 써요. 이 프로그램을 Render의 서버 한 대에서 돌리고, 학생 태블릿과 선생님 컴퓨터는 웹소켓으로 그 서버와 실시간으로 연결돼요. 서버 지역은 한국과 가까운 **싱가포르**로 정해 뒀어요.

### 비용 (2026년 11월 Render·Neon 요금 페이지 기준, 바뀔 수 있어요)

| 구성 | 월 비용 | 특징 |
|---|---|---|
| **추천: Render Starter + 디스크 1GB** | 약 **$7.25** (인스턴스 $7 + 디스크 $0.25) | 늘 켜져 있어서 바로 열려요. 데이터는 서버 디스크에 저장돼요. |
| 무료: Render Free + Neon Postgres Free | **$0** | 15분 동안 아무도 안 쓰면 잠들고, 다시 열 때 **약 1분** 걸려요. Render가 무료 서버를 아무 때나 재시작할 수 있어요. 데이터는 Neon 데이터베이스에 저장돼요. |

- Render의 Hobby 작업 공간은 기본료가 $0이고, 쓴 인스턴스 요금만 내요. 결제는 Render 계정에 카드를 등록해요.
- Hobby 요금제는 한 달 데이터 전송 5GB가 포함돼요. 한 반 수업 한 번에 수십 MB 정도라 넉넉해요.
- **시범 수업 당일에는 추천 구성을 권해요.** 시범이 끝나면 Render에서 서비스를 멈추거나 지워 요금을 멈출 수 있어요.

## 올리는 방법 (추천 구성, 15분 정도)

1. **GitHub에 올리기**
   - https://github.com 에 가입하고 **New repository**로 저장소를 만들어요 (Private도 괜찮아요).
   - 저장소 화면의 **uploading an existing file**을 눌러, 이 폴더 안의 파일을 모두 끌어다 놓고 **Commit changes**를 눌러요.
2. **Render에 연결하기**
   - https://render.com 에 GitHub 계정으로 가입해요.
   - **New → Blueprint**를 누르고 방금 만든 저장소를 골라요. `render.yaml` 설정대로 서버와 디스크가 준비돼요.
   - `TEACHER_ID`, `TEACHER_PW` 값을 넣고 **Apply**를 눌러요. 카드 등록을 요청하면 등록해요.
3. 몇 분 뒤 **Live** 표시가 뜨면 서비스 화면 위쪽의 `https://….onrender.com` 주소가 완성된 주소예요.
   - 선생님은 그 주소 뒤에 `/teacher`를 붙여 들어가요.
   - 학생 주소는 선생님 화면 오른쪽 위 **"학생 주소"**를 누르면 복사돼요.

### 무료 구성으로 올리기

1. https://neon.com 에 가입하고 프로젝트를 만든 뒤, **Connection string**(postgresql://…)을 복사해요.
2. Render에서 **New → Web Service**로 저장소를 고르고 다음처럼 설정해요.
   - Region `Singapore`, Build Command `npm install --omit=dev`, Start Command `npm start`
   - Instance Type `Free`
3. 환경 변수에 `DATABASE_URL`(복사한 주소), `TEACHER_ID`, `TEACHER_PW`를 넣고 만들어요.
4. 수업 **5분 전에** 선생님 주소를 한 번 열어 서버를 깨워 두세요.

## 수업할 때 (모니터 + TV)

1. 컴퓨터에 TV를 연결하고, 화면 설정을 **확장**으로 해요 (Windows: `Win + P` → 확장).
2. 모니터에서 선생님 주소로 로그인 → 오늘 수업 미리보기 → **수업 시작**.
3. 대기실의 **"TV 화면 열기"**를 누르면 새 창이 열려요. 그 창을 TV 쪽으로 끌어다 놓고 **전체 화면**을 눌러요.
   - 대기실 버튼이 초록색 **"TV 화면 연결됨"**으로 바뀌면 연결된 거예요.
   - TV에는 큰 QR, 수업 코드, 들어온 학생 닉네임이 보여요.
4. 학생들이 QR을 찍어 들어오면 **시작하기**를 눌러요.
5. 모니터에서 **다음 / 이전 단계 / 결과 보기**를 누르면 TV와 학생 태블릿이 함께 넘어가요.
   - **TV**: 학생 화면만 크게 나와요. 결과 공개 애니메이션도 TV에서 같이 재생돼요.
   - **모니터**: 버튼, 답한 학생 수, 다음 화면 미리보기가 함께 보여요.
6. **수업 끝내기**를 누르면 결과가 저장되고 결과 화면이 열려요. 결과는 모니터에만 나오고 TV에는 "수업이 끝났어요"만 보여요.

## 수업 전날 꼭 해 볼 것 (리허설)

1. **학교 Wi-Fi와 학교 태블릿으로** 학생 주소를 열어 봐요. 학교 네트워크가 `onrender.com`을 막는지 확인해요.
2. 태블릿 2~3대로 QR 입장 → 시작 → 단계 넘기기 → 결과 보기 → 끝내기까지 한 번 해 봐요.
3. 수업 중 태블릿 한 대를 새로고침해서, 하던 단계와 고른 답이 그대로인지 확인해요.
4. 화면 아래에 빨간 **"연결이 끊겼어요"**가 오래 뜨면 Wi-Fi를 확인해요. 연결이 돌아오면 자동으로 다시 맞춰져요.

## 보안과 개인정보

- 모든 주소는 https로 열려요 (Render가 인증서를 자동으로 붙여요).
- 학생은 실명 없이 닉네임으로만 들어오고, 닉네임과 활동 답만 저장돼요.
- 선생님 비밀번호는 암호화(scrypt)해서 저장해요. 로그인은 14일 동안 유지되고, 비밀번호를 바꾸면 다른 기기의 로그인은 끊겨요.
- 로그인이나 코드 입력을 여러 번 틀리면 5분 동안 막혀요.
- 학생 기기는 지금 열린 수업 하나와 자기 기록만 받을 수 있어요. 클래스, 결과, 다른 학생 기록은 선생님 로그인으로만 볼 수 있어요.
- 학교에서 학생 답을 다루는 만큼, 시범 운영 전에 학교의 개인정보 기준을 담당 선생님과 확인해 주세요.

## 지금 버전의 한계

- 선생님 계정은 하나예요.
- AI 답변은 미리 정해 둔 예시 답이에요 (실제 AI 연결 없음).
- 콘텐츠 추가는 TXT 파일의 글만 읽어요. PDF·HWP·PPT는 파일 이름만 쓰고, 내용은 편집 화면에서 채워요.
- 만든 교육 자료(장)는 아직 수업 진행 화면에는 나오지 않아요.
- 글꼴은 Google Fonts에서 받아요. 학교 네트워크가 막으면 기본 글꼴로 보여요 (동작은 그대로예요).

## 내 컴퓨터에서 먼저 시험해 보기 (개발자용)

```
npm install
npm start          # http://localhost:3000 (학생) / http://localhost:3000/teacher (선생님)
```

`DATABASE_URL`이 없으면 `data/wia-data.json` 파일에 저장해요.

## 파일 구성

- `server.js`: 웹 서버, 로그인, 실시간 연결(Socket.IO), QR 생성, 저장(파일 또는 PostgreSQL)
- `public/index.html`: 학생 화면, 선생님 화면, TV 화면
- `render.yaml`: Render 배포 설정 (추천 구성)
