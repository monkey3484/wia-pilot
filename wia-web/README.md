# 위아 WIA 웹 서비스

선생님 화면, TV 화면, 학생 웹, 선생님 회원가입, 관리자 모니터링을 하나의 웹 서비스로 묶었어요.

## 주소

| 누가 | 주소 | 하는 일 |
|---|---|---|
| 학생 | `/` | QR을 찍거나 수업 코드 입력 → 이름 → 수업 참여 |
| 선생님 | `/teacher` | 이메일로 로그인, 클래스·콘텐츠 관리, 수업 진행 |
| TV | `/teacher?tv=1` | 수업 화면에서 "TV 화면 열기"를 누르면 열려요 |
| 선생님 회원가입 | `/signup` | 가입 신청 → 이메일 인증 → 관리자 승인 |
| 비밀번호 찾기 | `/forgot` | 메일로 재설정 링크 받기 |
| 관리자 | `/admin` | 모니터링, 승인, 제한, AI 프롬프트 관리 |

## 환경 변수 (Render → 서비스 → Environment)

| 이름 | 꼭 필요? | 설명 |
|---|---|---|
| `DATABASE_URL` | 무료 구성이면 필수 | Neon PostgreSQL 주소. 없으면 서버 파일에 저장해요. |
| `ADMIN_ID` | 선택 (기본 `admin`) | 관리자 화면 아이디 |
| `ADMIN_PW` | **필수** | 관리자 화면 비밀번호. 없으면 `/admin`에 로그인할 수 없어요. 길고 어렵게 정해 주세요. |
| `PUBLIC_URL` | 권장 | `https://wia-pilot.onrender.com`처럼 서비스 주소. 메일 속 링크와 QR에 쓰여요. |
| `ANTHROPIC_API_KEY` | AI를 쓸 때 | Claude API 키 (`sk-ant-…`). 없으면 **시범 모드**: 자료를 올려도 예시 틀로 만들어져요. |
| `RESEND_API_KEY` | 메일을 보낼 때 | Resend API 키 (`re_…`). 없으면 **시범 모드**: 메일을 보내지 않고 관리자 메일함에만 남겨요. |
| `MAIL_FROM` | 도메인 인증 뒤 | 보내는 주소. 예) `위아 WIA <no-reply@우리도메인.kr>`. 비우면 `onboarding@resend.dev`(Resend 가입 이메일로만 보낼 수 있어요). |
| `ADMIN_EMAIL` | 선택 | 새 선생님이 승인을 기다릴 때 알림을 받을 관리자 이메일 |
| `TEACHER_ID`, `TEACHER_PW` | 선택 | 데이터가 하나도 없을 때 처음 만드는 선생님 계정 |

환경 변수를 바꾸면 Render가 서버를 다시 시작해요(1~2분). 수업 중에는 바꾸지 마세요.

## 선생님 계정

- **처음 계정**(`wia2026` 같은 예전 아이디)은 그대로 로그인돼요. 예전 클래스·콘텐츠·결과는 이 계정의 것으로 자동으로 옮겨져요.
- **새 선생님**은 `/signup`에서 이름, 학교, 이메일, 학교급, 과목, 비밀번호를 적고 개인정보 동의 후 신청해요.
  1. 이메일 인증: 메일의 "이메일 인증하기" 버튼 (24시간 유효)
  2. 관리자 승인: `/admin` → 선생님 → 승인. 승인되면 선생님께 안내 메일이 가요.
  - 메일 시범 모드(RESEND_API_KEY 없음)에서는 메일이 안 가므로, 신청이 바로 "승인 대기"로 들어와요. 관리자가 승인하면 돼요.
  - 관리자 → 제한 설정 → "바로 승인할 학교 이메일 도메인"에 `sen.go.kr` 같은 도메인을 넣으면, 그 도메인 선생님은 메일 인증만으로 바로 열려요.
- 선생님마다 클래스·콘텐츠·수업·학생 기록이 따로 저장되고, 다른 선생님 것은 보이지 않아요.

## AI 콘텐츠 만들기 (Claude)

선생님이 수업 자료 만들기에서 파일을 올리고 "AI로 콘텐츠 만들기"를 누르면:

1. 서버가 파일을 받아요. PDF·그림은 Claude가 직접 읽고, 워드(docx)·PPT(pptx)·한글(hwpx)·TXT는 서버가 글을 뽑아 넣어요. 옛 HWP·PPT·DOC는 읽지 못해서 "PDF로 저장해서 올려 주세요"라고 안내해요.
2. 관리자 화면에서 정한 프롬프트와 모델로 Claude를 불러요. 프롬프트는 "자료에 없는 내용은 쓰지 말고, 부족하면 (확인 필요: …)로 남겨라"를 지키게 되어 있어요.
3. Claude는 정해진 모양(JSON 도구)으로만 답해요: 교육 화면 N장 + "AI에게 잘 묻기" 활동 7단계 내용 + 근거(파일·쪽) + 확인 필요 목록.
4. 결과가 편집 화면에 열리고, 노란 "확인 필요"부터 선생님이 고쳐요.

- 기록: 관리자 → AI 기록에서 누가, 어떤 자료로, 몇 토큰을 쓰고, 얼마가 들었는지와 뽑아낸 글·결과를 볼 수 있어요.
- 비용 감각 (claude-sonnet-5-5, 입력 $2 / 출력 $10 per 1M 토큰): 자료 20쪽 PDF로 8장 만들기 ≈ 입력 3~5만 + 출력 6~8천 토큰 ≈ **$0.1~0.2 (150~300원)**. 정확한 값은 AI 기록에 나와요.
- 모델: 관리자 → 프롬프트·모델에서 바꿀 수 있어요 (sonnet 5.5 기본, haiku 5.5는 훨씬 싸지만 글이 단순해요).

## 관리자 화면 (`/admin`)

| 탭 | 볼 수 있는 것 · 할 수 있는 것 |
|---|---|
| 개요 | 접속한 선생님·학생 수, 진행 중 수업, AI 이번 달 비용·토큰·예산, 서버 메모리·CPU, DB 크기, 24시간 그래프 |
| 선생님 | 계정 목록(상태, 접속 기기, 접속 학생, 콘텐츠 수, AI 사용, 1시간 사용량), 승인·멈추기·로그아웃·비밀번호 바꾸기·지우기, **선생님별 제한**, 콘텐츠·AI 기록 보기 |
| 수업 중 | 열린 수업마다 선생님, 코드, 입장 학생/정원, 지금 연결된 학생, 학생 이름 |
| AI 기록 | 생성마다 자료, 뽑아낸 글, 결과, 확인 필요, 토큰, 비용, 걸린 시간 |
| 프롬프트·모델 | 시스템 프롬프트·요청 틀 고치기(버전 저장, 예전 버전으로 되돌리기), 모델·최대 토큰·temperature, AI 켜고 끄기 |
| 제한 설정 | 기본 제한(수업당 학생 수, AI 하루/한 달 횟수, 파일 수·용량, 최대 장수, 콘텐츠 수), AI 한 달 예산, 전체 동시 학생 수, AI 동시 생성 수, 회원가입 받기, 자동 승인 도메인 |
| 메일함 | 보낸 메일과 결과, 시범 모드일 때 인증·재설정 링크, 시험 메일 보내기 |

제한이 걸리면: 정원이 차면 학생 입장 화면에 "정원이 다 찼어요", AI 횟수를 넘으면 선생님 화면에 안내, 예산을 넘으면 AI 만들기가 멈춰요.

## 저장 (데이터베이스)

`wia_store` 표 하나에 행으로 저장해요 (`DATABASE_URL`이 없으면 `DATA_DIR/wia-data.json`).

| 행 | 내용 |
|---|---|
| `t:<id>` | 선생님 계정 (이름, 이메일, 학교, 상태, 암호화한 비밀번호, 개별 제한) |
| `kv:<id>:wia-teacher-draft-v5` | 그 선생님의 클래스·콘텐츠·결과 |
| `kv:<id>:wia-live` | 그 선생님의 지금 수업 |
| `kv:<id>:wia-stu:<학생>` | 학생 기록 (이름, 답) |
| `meta:cfg` | 관리자 설정 (제한, 모델, 프롬프트 버전) |
| `meta:sessions` | 로그인 세션 |
| `log:<id>` | AI 생성 기록 (최근 2000개) |
| `mail:<id>` | 메일 기록 (최근 300개) |

올린 원본 파일은 저장하지 않고, 뽑아낸 글(파일당 2만 자까지)과 결과만 남겨요. Neon 무료 1GB 안에서 충분해요.

## 보안

- 비밀번호는 scrypt로 암호화해 저장해요. 인증·재설정 링크는 해시로만 저장해요.
- 로그인·코드 입력·관리자 로그인을 여러 번 틀리면 잠시 막혀요. 회원가입은 한 IP에서 1시간에 6번까지.
- 관리자 세션은 12시간, 선생님 세션은 14일. 관리자가 계정을 멈추면 그 선생님 화면은 바로 로그아웃돼요.
- 학생은 지금 열린 자기 수업과 자기 기록만 받을 수 있어요.
- API 키는 Render 환경 변수에만 넣고, 채팅·GitHub에 올리지 마세요.

## 내 컴퓨터에서 시험 (개발자용)

```
npm install
ADMIN_PW=아무거나 npm start    # http://localhost:3000
```

## 파일 구성

- `server.js`: 웹 서버, 계정·가입·인증, 관리자 API, 실시간 연결, 저장
- `lib/ai.js`: 자료 읽기, Claude 호출, 기본 프롬프트, 결과 모양
- `lib/mail.js`: Resend 메일과 메일 문구
- `public/index.html`: 학생·선생님·TV 화면
- `public/account.html`: 회원가입·비밀번호 찾기
- `public/admin.html`: 관리자 모니터링
